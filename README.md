# Suite360 Films — Landing Page

Projeto em desenvolvimento etapa por etapa. Antes de mexer em qualquer coisa, leia:

- [PLANEJAMENTO.md](./PLANEJAMENTO.md) — arquitetura, stack, design system e roadmap.
- [CHECKLIST.md](./CHECKLIST.md) — progresso fase a fase.

## Desenvolvimento

```bash
npm run dev          # servidor de desenvolvimento (http://localhost:3000)
npm run build        # build de producao
npm run lint         # eslint
npm run type-check   # verificacao de tipos (tsc --noEmit)
npm run format       # formata com prettier
npm run format:check # verifica formatacao sem escrever
```

## Stack

Next.js (App Router) + TypeScript + Tailwind CSS v4 + Framer Motion (`motion`) + `lucide-react`.
